# Environment variables

Generated by `npm run docs` from the source code. Do not edit this page by hand.

The API validates these variables when it starts and refuses to boot when a required one is missing or invalid. Set them in `.env` for local runs, or in the environment for Docker and production.

| Variable | Required | Default | Accepted values | Purpose |
| --- | --- | --- | --- | --- |
| `NODE_ENV` | No | `development` | `development`, `test`, `production` | Runtime mode: development, test or production. |
| `PORT` | No | `3000` | integer | TCP port the HTTP server listens on. |
| `DATABASE_URL` | Yes | None | string | PostgreSQL connection string used by the API and the migrations. |
| `JWT_SECRET` | Yes | None | string | Secret that signs access tokens. Use at least 32 characters. |
| `OBSERVE_APP_KEY` | No | None | string | NestJS Observe application key. Without it no telemetry is sent. |
| `OBSERVE_APP_SECRET` | No | None | string | NestJS Observe application secret, paired with OBSERVE_APP_KEY. |
